# A/B Test Analysis

This project evaluates whether a new offer affected the first-purchase conversion rate.

## What I did

- Calculated conversion rates for the control and test groups in Python.
- Tested whether the difference between the groups was statistically significant.
- Built a Power BI dashboard to compare the results and summarized my findings in a short report.
